# BODEX Proxy

A branded Windows desktop build based on the upstream ProxiFyre project.

## Project goals

- Preserve the upstream proxy engine and routing behavior.
- Retain SOCKS5 proxy support, TCP/UDP handling, per-application routing, DNS policy, and leak-protection behavior provided by the selected upstream version.
- Apply BODEX branding and a black/cyan user interface theme.
- Keep upstream license notices and publish the corresponding modified source as required by the upstream license.

## Upstream

This project is intended to be based on [wiresock/ProxiFyre](https://github.com/wiresock/proxifyre), pinned to a reviewed release before building.

## Build status

No Windows installer or executable is published yet. Build and test workflows must be completed and verified before distributing binaries.
